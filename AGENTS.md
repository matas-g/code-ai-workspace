# Framework maintenance

All skills created by Code-AI or for maintaining this framework must use the `ca-` prefix. Keep the skill folder name, SKILL.md frontmatter name, invocation examples, helper/resource links, runtime inventory and release mappings consistent. Preserve this convention when adding future skills. Do not rename unrelated third-party or repository-owned skills.

Keep this maintainer file outside the product release. Track manual testing in MANUAL_TESTS.md; automated checks do not certify IDE skill discovery. Use _tmp for temporary development files. When creating a newer release ZIP, move the superseded ZIP and its checksum to _old zips without overwriting archived files.
